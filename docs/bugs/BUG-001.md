# BUG-001 : Le compteur du mot de passe affiche /20 au lieu de /40

| Champ | Valeur |
|---|---|
| **Famille** | Interface |
| **Sévérité** | Faible (S4) |
| **Priorité** | Basse (P3) |
| **Exigence violée** | AC-01.5, règle « mot de passe 8 à 40 caractères » |
| **Environnement** | minishop-app, `BUGS=BUG-001` ou `BUGS=on`, Node.js 22, Chromium (Playwright) |
| **Statut** | Ouvert (défaut volontaire, voir `minishop-app`) |

## Étapes de reproduction

1. Ouvrir <http://localhost:3000> et aller sur « Inscription ».
2. Cliquer dans le champ « Mot de passe » et saisir `abcde`.

## Résultat attendu

Le compteur affiche `5/40` (la limite réelle est de 40 caractères).

## Résultat obtenu

Le compteur affiche `5/20`. À vide il affiche `0/20`. Le serveur et le contrôle côté client acceptent bien jusqu'à 40 caractères : seule l'information affichée est fausse.

## Impact

L'utilisateur croit que son mot de passe est limité à 20 caractères et peut choisir un mot de passe plus faible qu'il ne le voudrait. Aucune donnée n'est exposée.
