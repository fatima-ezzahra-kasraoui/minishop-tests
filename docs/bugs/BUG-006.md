# BUG-006 : Le titre de la recherche est injecté en HTML brut (XSS réfléchi)

| Champ | Valeur |
|---|---|
| **Famille** | Injection |
| **Sévérité** | Haute (S2) |
| **Priorité** | Haute (P1) |
| **Exigence violée** | AC-04.3, SEC-04 |
| **Environnement** | minishop-app, `BUGS=BUG-006` ou `BUGS=on`, Node.js 22, Chromium (Playwright) |
| **Statut** | Ouvert (défaut volontaire, voir `minishop-app`) |

## Étapes de reproduction

1. Ouvrir « Produits ».
2. Dans la recherche, saisir `<b>test</b>` (ou `<img src=x onerror=...>`) puis valider.

## Résultat attendu

Le titre affiche le texte littéral : « Résultats pour : <b>test</b> ».

## Résultat obtenu

Le texte est interprété comme du HTML : « test » apparaît en gras, et une balise `<img>` avec un gestionnaire `onerror` est insérée dans la page, ce qui permet d'exécuter du JavaScript dans la session de l'utilisateur. Seul le titre est touché : les noms de produits restent affichés comme du texte.

## Impact

Exécution de script dans le contexte de la page : vol du jeton JWT conservé dans `localStorage`, actions au nom de l'utilisateur. Classe OWASP : Injection (XSS).

- `tests/security/xss.spec.ts` : balise en gras, image avec gestionnaire d'évènement, attribut injecté dans un lien (le test regarde si l'élément a été créé dans le DOM, sans exécuter de script)

Ces tests utilisent `expectBug('BUG-006')` : en mode `BUGS=on` leur échec est attendu et rapporté comme réussi ; en mode `BUGS=off` ils doivent passer.
