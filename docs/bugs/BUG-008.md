# BUG-008 : En-têtes de sécurité absents, `X-Powered-By` présent

| Champ | Valeur |
|---|---|
| **Famille** | Configuration |
| **Sévérité** | Moyenne (S3) |
| **Priorité** | Moyenne (P3) |
| **Exigence violée** | SEC-03 |
| **Environnement** | minishop-app, `BUGS=BUG-008` ou `BUGS=on`, Node.js 22, Chromium (Playwright) |
| **Statut** | Ouvert (défaut volontaire, voir `minishop-app`) |

## Étapes de reproduction

1. Appeler n'importe quelle route :
   ```bash
   curl -I http://localhost:3000/
   ```

## Résultat attendu

Présence de `Content-Security-Policy`, `X-Content-Type-Options: nosniff`, `X-Frame-Options` et `Referrer-Policy` ; absence de `X-Powered-By`.

## Résultat obtenu

Aucun des quatre en-têtes de sécurité n'est envoyé et `X-Powered-By: Express` révèle la technologie du serveur. Constaté sur `/`, `/api/health` et `/api/products`.

## Impact

Aucune défense en profondeur : pas de CSP pour limiter un XSS, page intégrable dans une iframe (clickjacking), détection de type MIME par le navigateur, technologie divulguée. Classe OWASP : Security Misconfiguration.

## Tests automatisés qui le détectent

- `tests/security/headers.spec.ts` : un test par en-tête et par route (15 tests : 4 en-têtes + `X-Powered-By`, sur 3 routes)

Ces tests utilisent `expectBug('BUG-008')` : en mode `BUGS=on` leur échec est attendu et rapporté comme réussi ; en mode `BUGS=off` ils doivent passer.
